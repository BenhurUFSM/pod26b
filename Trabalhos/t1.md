# Trabalho 1 - desempenho de ordenação interna

Gera gráficos de desempenho de vários algoritmos de ordenação interna.
Cada algoritmo deve ter seu tempo de execução medido para ordenar vetores de tamanho 8, 16, 32, 64 etc até 1G ou até o que for possível alocar ou até o menor tamanho cujo tempo de ordenação exceder 5s.
Para cada tamanho, deve-se, antes de ordenar, inicializar o vetor com dados:
- já previamente ordenado,
- já ordenado em ordem inversa,
- aleatoriamente desordenado.

Os algoritmos são divididos em 2 grupos:
- algoritmos simples (bolha, inserção, seleção, shell)
- algoritmos rápidos (heap, merge, quick).

Para cada grupo e forma de inicialização, gere um gráfico com uma linha para cada algoritmo, com o tamanho do vetor no eixo `x` e o tempo de execução no `y`.

É fornecido o arquivo `ordena.c`, que contém a implementação dos algoritmos e a medição do tempo.

Você deve fazer uma pequena alteração na medição do tempo, para diminuir a probabilidade de ter o tempo afetado por atividades espúrias do computador.
Cada medida deve ser realizada mais de uma vez, até que a diferença de tempo entre as duas mais rápidas não exceda 1% da mais rápida.
Considere então como medida a mais rápida.
