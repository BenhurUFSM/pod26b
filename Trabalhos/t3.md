
# Trabalho 3 - comparação de compressores

Encontre 3 programas de compressão sem perdas (ou opções de um mesmo programa), que utilizem 3 métodos de compressão diferentes.
Consiga 3 arquivos com textos em português, com 3 tamanhos bem diferentes (diferença de mais de 10 vezes, o menor deles não menor que 1kbyte).
Consiga 3 arquivos com imagens de retrato (a cara de uma pessoa ocupa uma boa parte da imagem) em formato raw, com 3 tamanhos bem diferentes.
Converta as 3 imagens para 3 arquivos em formato jpeg, com qualidade alta.
Use os 3 programas para comprimir os 9 arquivos, e faça uma relatório.
O relatório deve incluir descrição do experimento, dos programas, dos arquivos.
O relatório deve incluir comparação de desempenho (tempo, espaço, taxa de compressão).
